# MSP IT Support and Systems Administration Labs

## Project Overview

This repository documents a collection of hands-on IT administration, Microsoft 365, endpoint management, and Managed Service Provider (MSP) support labs.

The project focuses on developing and demonstrating practical technical competencies required to support business IT environments, manage cloud-based services, troubleshoot infrastructure issues, and maintain secure and reliable IT operations.

Each lab includes its objectives, implementation procedures, configuration details, screenshots, testing and validation results, troubleshooting experiences, and lessons learned.

## Project Objectives

- Develop practical Microsoft 365 administration skills.
- Demonstrate user, licence, and identity management.
- Configure and troubleshoot Exchange Online services.
- Explore Microsoft Entra ID and identity security.
- Understand and implement Remote Monitoring and Management (RMM) workflows.
- Practise endpoint monitoring, maintenance, and troubleshooting.
- Understand MSP service delivery, ticket management, and SLA requirements.
- Develop structured IT troubleshooting and technical documentation skills.

## Lab Documentation Standards

Each practical lab is documented using a consistent structure:

1. Lab Overview
2. Purpose and Objectives
3. Lab Environment and Requirements
4. Implementation Procedure
5. Configuration Screenshots and Evidence
6. Testing and Validation
7. Troubleshooting and Resolutions
8. Results and Achievements
9. Lessons Learned
10. Conclusion

Code snippets and automation scripts are included where applicable.

## Project Approach

The labs are implemented in controlled test environments using simulated business scenarios.

Configuration steps, screenshots, commands, and test results are documented to provide practical evidence of the skills developed.

All credentials, access tokens, confidential information, and sensitive configuration details are excluded from the public repository.
